# Runtime Evidence

Use this directory for evidence that materially affects capability, integration, evaluation, regression, or promotion decisions.

A minimal evidence note should contain:

- Date / run identifier
- Objective
- Relevant environment and versions
- Commands or actions actually executed
- Expected result / pass criteria
- Observed result
- Status: VERIFIED / DERIVED / ASSUMED / UNVERIFIED / CONFLICTED / UNKNOWN
- Known limitations or unresolved items

Do not create evidence entries for routine noise. Preserve evidence that changes what the workbench is allowed to claim or promote.
